Theme

The base decides which built-in palette every token you leave empty inherits from.

Elevation ladder

Each step must be brighter than the one before it, in both bases. Invert it and every raised surface reads as sunken.

Required tokens

Written to the file verbatim. Use 6-digit hex — LC's resolver only parses #rrggbb when deriving the rest.

Optional tokens

Left empty, each is computed from a required token. The greyed value is what LC will derive — type to pin it instead.

Extended tokens

Left empty, these fall back to the base theme's indigo defaults — they do not follow your accent. Set them for any non-indigo theme.

Code theme

Picks the Prism grammar colors and fills the two code-block tokens with that theme's real surface colors.

Prism could not be loaded from the CDN, so the code preview is unhighlighted. Everything else — including the code-block colors below — is unaffected.
